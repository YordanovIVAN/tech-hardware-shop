# Документация на проекта - TechGear Hub

## 1. Структура на проекта
Проектът представлява контейнеризирано уеб приложение (онлайн магазин за компютърен хардуер и гейминг периферия), организирано в следната структура:

* `img/` — Директория с изображения на продуктите (`rtx4070.jpg`, `keyboard.jpg`, `monitor.jpg`).
* `index.php` — Начална страница, показваща каталога с продукти и техните цени (в лева и евро).
* `cart.php` — Пазарска количка, сумираща цените на избраните хардуерни компоненти.
* `add.php` & `remove.php` — Скриптове за обработка и управление на потребителските сесии.
* `db.php` — Конфигурация за връзка с MySQL сървъра през PDO.
* `my_shop.sql` — SQL скрипт за инициализация на базата данни и примерните данни.
* `Dockerfile` — Инструкции за изграждане на персонализиран Docker образ за PHP уеб приложението.
* `compose.yml` — Декларативен файл за дефиниране, свързване и управление на многоконтейнерната среда.

---

## 2. Как работи всеки от компонентите
1. **Уеб приложение (PHP 8.2 + Apache):** Използва се персонализиран уеб сървър, който обработва потребителските заявки и визуализира продуктите. Дизайнът е базиран на Bootstrap 5 с модерна тъмна (Dark/Neon) геймърска тема. Количката се управлява на ниско PHP ниво чрез native сесии (`$_SESSION`), без излишно натоварване на базата данни.
2. **База данни (MySQL 8.0):** Съхранява релационната таблица `products` (с полета за `id`, `name`, `price`, `image`). Използва официален релационен образ на MySQL.

---

## 3. Комуникация между услугите
Мрежовата комуникация е изолирана в Docker среда:
* **DNS резолвване:** В `db.php` за адрес на хоста вместо `localhost` е зададено името на MySQL услугата (`$host = 'db';`). Вграденият в Docker DNS сървър автоматично пренасочва заявките към вътрешния IP адрес на контейнера.
* **Автоматична инициализация:** SQL скриптът `my_shop.sql` се обвързва чрез volume в директорията `/docker-entrypoint-initdb.d/` на MySQL, което гарантира автоматичното наливане на структурата и данните при първоначално стартиране.
* **Контрол на зависимостите:** Директивата `depends_on` кара уеб сървъра да изчака стартирането на MySQL базата данни, преди самият той да започне да приема заявки.
